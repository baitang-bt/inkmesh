# 高效 UI 提示词

适用范围：**画板工作区**，以及 **他人光标和名字**。  
大厅用 [特色 UI](distinctive-ui.md)。不要把切角、网格背景、扫光按钮做进画布周围。

现状以 `app/games/collab_canvas/static/css/collab-workspace.css` 为准（注释为 Krita/Magma 式直角 dock）。改样式时保持下面的密度，不要为了好看加一层装饰。

## 提示词

做绘画时一直开着的界面（中文）。先保证手和眼睛留在画布上，布局为连续操作服务。不要做成落地页，也不要做成特色终端。

气质

- 绘画软件工作区：直角、密、安静。参考 Krita 的停靠面板，不参考它的启动页。
- 大面积中性灰。强调色只出现在当前工具、主操作和选中行。
- 不要切角、网格背景、径向光、扫光、玻璃、大圆角卡片。
- 他人光标和名字也走这套：小圆点、细环、10px 名字标签。每人一个纯色即可，不要光晕、切角标、等宽大写。

颜色

- 底 `#181818`，面板 `#2b2b2b`，抬高一档 `#313131`。
- 分隔 `#3d3d3d`。字 `#e8e8e8`，次要字 `#9a9a9a`。
- 画布外围 `#535353`，把纸和界面分开。
- 强调 `#3d8eff`，只用于激活和主按钮。状态条可以用 `#fbbf24`，不要铺开。
- 光标色是每人自己的 `--cursor-color`（缺省 `#60a5fa`）。点 6px（落笔时 8px），白边 1px；标签用同一颜色、白字。

表面

- 直角。按钮、徽章、提示、图层行的圆角都是 0。光标标签最多 2px。
- 1px 实线分隔。阴影只给浮出的提示和光标标签，短、偏黑。
- 面板标题是一条矮栏，不是英雄区。

字与图标

- 界面用系统无衬线。工作区按钮 12px、字重 600；提示 11px；顶栏标题 13px；光标名字 10px、字重 700。
- 图标用 Material Symbols Outlined，线性，跟按钮一起显示；纯图标按钮保留文字提示。
- 不加载装饰字体，不用等宽大写做分区标签。

控件

- 工具在约 52px 窄轨里，一列图标。选项（颜色、粗细）在右侧面板，不挂在工具按钮上。
- 图层和画板是列表加底栏图标：新建、编组、复制、上下移、属性。
- 顶栏放房间号、人数、撤销、导出、链接、全屏、成员、设置、离开。房间号用等宽、可扫读。
- 悬停只变色，不位移、不扫光。进行中的事写在状态条，不弹装饰提示。
- 设置和成员是同一套灰面板上的表单和名单。

布局

- 左工具轨、中画布、右栏（上：调色和粗细；下：图层 / 画板）。左右可对调，分隔条可拖。
- 右栏默认约 280px。顶栏约 40px。
- 画布上只留缩放角标和他人光标。权限、导出格式、笔压放在按需打开的面板里。
