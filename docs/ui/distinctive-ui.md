# 特色 UI 提示词

适用范围：**大厅**（进站、我的画板、最近、一起画过的人、进房）。  
不用于画板工作区，也不用于他人光标和名字。那两处用 [高效 UI](efficient-ui.md)。

来源：cask 工作区的界面提示词。仓库里没有单独的提示词文件；色值与 `projects/cask/src/cask/ui_theme.py`、`projects/cask/src/cask/webui/assets/app.css` 一致。Inkmesh 大厅是网页，落地时取气质、颜色、表面、字和控件，不照搬 cask 的 macOS webview、启动页和原生标题栏。

## 提示词

做界面（中文）。先定风格，布局为风格服务，不要做成营销落地页或通用后台。

气质

- 深色战术终端：冷静、密、偏工具，带一点明日方舟的冷色科技感。
- 强调色只点在关键动作、选中态、细边上，大面积留灰度。
- 不要紫渐变、玻璃拟态、大圆角卡片、Inter、以及任何版权游戏素材。

颜色

- 深色是中性灰，不要偏蓝：底 `#0a0a0a`，层级 `#121212` / `#1a1a1a`，字 `#eeeeee`，次要字 `#9a9a9a`。
- 浅色是冷灰白：底 `#e8ecf2`，面板 `#f4f6fa` / `#ffffff`，字 `#0f172a`，次要字 `#334155`，对比要够。罗德岛蓝的浅色底可以略偏蓝（`#e6eef6`）。
- 外观三档：跟随系统 / 浅色 / 深色。启动页、弹窗、内嵌标题栏跟同一套颜色走。
- 强调色四套，只换强调、不换骨架：琥珀金 `#f3c21b`（默认，上面用墨色字）、罗德岛蓝 `#00d2ff`、青玉 `#3dd68c`、朱红 `#e85d4c`。第二强调接近青 `#4fd1c5`。危险 `#ff5a6a`，成功 `#62e0a1`。
- 分割线和焦点环用强调色的低透明度。悬停是很淡的白或强调色洗。

表面

- 背景：很淡的强调色径向光，加上 48px 细网格，网格向边缘淡出。
- 面板、主按钮、菜单、品牌标用切角（clip-path 斜切约 8–14px），不要大圆角。小控件可以 2px 圆角；纯图标按钮可以是圆的。
- 左轨和浮层可以轻微模糊。阴影短、偏黑，浅色模式下阴影改成浅灰蓝。
- 品牌标是切角色块，里面是短字标，字色用强调色的墨色。

字与图标

- 界面：Avenir Next、Segoe UI、PingFang SC。等宽：SF Mono、IBM Plex Mono。不加载网络字体。
- 分区小标签用等宽、全大写、字距拉开，颜色用第二强调色。
- 图标用 Material Symbols Outlined，本地字体，线性、约 22px。

控件

- 主按钮填强调色、切角、字重 600；次按钮是线框或透明。悬停上移 1px，按下下移 1px。
- 进行中的动作在按钮内部做一道扫光，不弹多余提示。
- 筛选用分段按钮；菜单、下拉用应用内面板，不用系统原生 select。
- 弹窗和内嵌页的标题栏与主界面同一套 token：44px 高、底边强调色细线、同样的字体。

布局（只约束骨架）

- 桌面密度：一条窄图标轨（约 72px）加主工作区，信息靠面板边框和留白分层，不靠大卡片墙。
- 同一屏完成选择和操作；窄屏改为上下叠放。
- 对立状态做成同一控件的不同形态，同类功能放在一起。
